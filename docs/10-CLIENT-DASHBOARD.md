# Client dashboard
Routes: `/app` org selector; `/app/[tenant]/overview`; `/bots`; `/bots/new`; `/bots/[id]/settings`; `/bots/[id]/sources`; `/bots/[id]/knowledge`; `/bots/[id]/playground`; `/bots/[id]/install`; `/bots/[id]/conversations`; `/bots/[id]/analytics`; `/inbox` (P5), `/inbox/[conversation]`, `/contacts`, `/contacts/[id]`, `/followups`, `/settings/channels` (P6), `/settings/members`.
Bot create wizard: name → website URL (optional at foundation) → confirm → view bot. Source view shows status/errors/retry; knowledge review and publish explicit; playground displays citations and errors; install screen provides verified script; analytics show measured usage, not fabricated counts. Display role restrictions and empty/loading/error states. P1 implements auth, org selector and bot CRUD only; knowledge in P2, playground in P3, install/conversations/analytics in P4; inbox, contacts and follow-ups in P5; channel connections in P6; other screens can be deferred without fake UI.
