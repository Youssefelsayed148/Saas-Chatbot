# Platform admin
Separate route group `/platform`, protected by server-validated platform role (not tenant owner). Tenant directory, onboarding request creation, bot/source/job health, usage, incident and support audit. Any cross-tenant support operation requires actor attribution, reason and narrow authorization; never reuse client role checks to grant global access. Phase 1 adds only the `is_platform_staff` flag; the /platform area is built in P5-01. Original note: staff role model and tenant listing only, no impersonation or arbitrary edits. Later: retry jobs, pause bot, plan management, billing support and audit review.
