## Delivered

Preserved the existing V2 handoff and historical documents. Added npm-workspace Next.js/React/TypeScript frontend, modular FastAPI backend, local PostgreSQL/pgvector Compose stack, pinned dependencies, isolated tests, formatting/lint/type checks, and GitHub Actions validation. No business functionality, worker, widget or schema scaffold is included.

Health contract: GET /health returns 200 {"status":"ok"} independently of the database. GET /ready runs SELECT 1 against the configured database; returns 200 {"status":"ready"}, or safe 503 {"status":"not_ready"}. Neither endpoint returns credentials or database exception details. Configuration wraps the connection string in SecretStr. Unit tests override configuration and mock all connections.

The web foundation renders a real page without customer data or simulated feature success. Docker uses standalone Next.js output with static assets and server dependencies only; API/web processes run as UID 1000. Host builds use normal Next.js output. All published ports are loopback-only. The local database defaults to 55432, with configurable POSTGRES_PORT.
