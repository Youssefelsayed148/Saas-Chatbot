# Website Chatbot SaaS — start here
Multi-tenant Mojeeb-style SaaS for website clients: a business adds its data, publishes an AI agent, installs one script tag, and runs conversations through an inbox with human handoff, light CRM and follow-ups. WhatsApp/Messenger/Instagram arrive in P6 through ManyOsirisChat, which owns all Meta connectivity.
