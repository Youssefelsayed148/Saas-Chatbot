# Website Chatbot SaaS — start here
Standalone multi-tenant SaaS: a business adds its data (files and/or website), reviews and publishes it, tests the bot, installs one script tag, and monitors conversations, leads and analytics. ManyOsirisChat is connected only after the standalone product ships.
