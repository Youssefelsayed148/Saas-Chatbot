# Dashboard font

`dashboard-font.woff2` is a 0-byte placeholder. Replace it (same name, same
folder) with a self-hosted variable WOFF2 that has Latin and Arabic glyphs,
for example Cairo (variable, OFL licence) exported as one `.woff2`.
Keep the licence text next to it. The app never requests a font from the web.
If your file covers a different weight range, edit `weight` in `../fonts.ts`.
